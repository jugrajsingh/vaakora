Moving from Handy

Vaakora began as a fork of Handy, and it can copy your Handy data the first time it starts. It copies once and only reads the Handy folder. Quit the other app before dictating, because both use the same shortcut.

What is copied

  • It happens on the first start, when Vaakora has no data folder yet and Handy's settings file exists.
  • Copied: your settings (API keys and every value as they were, except start at login, which the copy turns off so only one app starts at login), both histories, recordings, the vocabulary file, models and web storage.
  • Left behind: logs, caches and the OpenVINO compile cache.
  • The Handy folder is only read and is never changed.
  • The new folder is private to you.
  • Files share disk blocks where the filesystem allows, so the copy may use less new space.

What you see

The first start shows the window with a card, and one desktop notification. The card reads:

Your settings and data were copied

Copied {{size}} from {{from}}: settings, history, recordings, vocabulary and models. That folder was not changed.

Files are shared on disk where the filesystem allows, so the copy may use less new space.

If the app that used this folder still starts when you log in, turn that off there, so only one app answers your shortcuts.

Buttons: Start at login, OK

{{size}} is the size copied and {{from}} is the Handy folder. OK hides the card for good. The notification says:

Imported your settings from {path}. Quit the other app before dictating; both use the same shortcut.

If the copy fails

A failure leaves only a small report file in the new folder. The card is titled "Your settings and data could not be copied". It names the error and says:

Copying from {{from}} failed: {{error}}. That folder was not changed. To try again, quit Vaakora, delete {{to}} and start Vaakora again.
